## 🎮 经典两阶段玩法

### 阶段一：猎人纳品进池 (Collecting)
1. 房主把集会所链接发到微信群里。
2. 猎人们点开链接，点击 **【📦 登记我的狩猎物资】**：
   - 填写自己的猎人昵称（如：太刀侠、猫猫头、苍蓝星）
   - 填写物资名称（例如：*🍖 熟肉抱枕 & 猎人特酿生啤杯、🐾 艾露猫肉垫防寒手套*）
   - 自定购买价格（例如：*¥68*，建议 50~70 元）
   - 挑选一个可爱的怪物猎人专属图标（熟肉、艾露猫爪、随从猫、神兵、防具、天鳞宝玉、大爆弹等）
3. 提交后，物资实时汇聚在主页的 **“🎁 集会所猎人纳品池”** 中，每个人都能实时看到大家准备的心意物资！

### 阶段二：封池开炉，全员狂欢抽奖 (Rolling)
1. 全员到齐后，大团长进入后台 (`/sillydog`)，点击 **【🔒 猎人物资已齐，一键封池开启抽奖！】**。
2. 所有人手机页面自动解锁 **🎰 艾露猫炼金摇奖机**：
   - 输入自己的猎人昵称，拉下摇杆 **【🕹️ 上手に焼けました！开摇！】**；
   - 炼金轮盘高速旋转，伴随咔哒声与悬念音效；
   - 轮盘定格，**全屏金色彩带喷涌 + 经典烤肉成功号角音效**！
   - 揭晓抽中谁带来的物资（公会严格保证：**100% 绝不会抽到自己带来的物资！**）；
   - 一键生成 **📜 猎人公会特别战报单**（带专属 QUEST CLEAR 公会红印章！），发群里炫耀打卡！
3. 大团长在后台点击 **【📋 一键复制集会所战报清单】**，生成清晰对账文本直接发群！
