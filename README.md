# 🎄 2026 圣诞礼物大抽奖 H5 (群友自报礼物池 · 纯随机Roll奖)

专为好友设计的**自选自报礼物池 + 街机抽奖机 (Slot Machine)** 网页应用。

针对 **50~70元** 预算区间：
- **每个人自己写买了什么、自定价格、自挑图标**；
- **全员公开礼物池，到齐后一键封池**；
- **100% 纯随机抽取，严格算法保证绝不抽到自己带的礼物**；
- **管理员独立后台，专属隐蔽入口**！

---

## 🎮 经典两阶段玩法

### 阶段一：自报礼物进池 (Collecting)
1. 房主把链接发到群里。
2. 朋友们点开链接，点击 **【🎁 登记我买的礼物】**：
   - 填写自己的昵称
   - 填写礼物名称（例如：*🔥 智能数显发热围巾、📻 复古黑胶无线小音响*）
   - 自定购买价格（例如：*¥68*，建议 50~70 元）
   - 挑选一个可爱的圣诞图标
3. 提交后，礼物实时出现在主页的 **“🎁 自报公开礼物池”** 中，每个人都能实时看到大家准备的心意好礼！

### 阶段二：封池开奖，全员狂欢抽奖 (Rolling)
1. 全员到齐后，房主进入后台 (`/sillydog`)，点击 **【🔒 礼物已到齐，一键封池开启抽奖！】**。
2. 所有人手机页面自动解锁 **🎰 街机圣诞摇奖机**：
   - 输入自己的昵称，拉下大红拉杆 **【🕹️ PULL!】**；
   - 摇奖轮盘高速飞转，伴随机械咔哒声与悬念音效；
   - 轮盘定格，**全屏金色彩带喷涌 + 胜利号角**；
   - 揭晓抽中谁带来的礼物（算法严格保证：**100% 绝不会抽到自己提交的那份！**）；
   - 一键生成中奖炫耀海报，发群里打卡！
3. 房主在后台点击 **【📋 一键复制公示总清单】**，生成清晰对账文本直接发群！
